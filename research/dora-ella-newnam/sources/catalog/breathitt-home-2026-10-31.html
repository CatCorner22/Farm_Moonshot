Welcome to Breathitt County on KYGenWeb

This KyGenWeb project is dedicated to maintaining genealogical information about our Breathitt County, Kentucky connecting families. This is an ongoing effort and needs your help. Any information you can add or correct contributes to the benefit of all Breathitt County family researchers.

Our web address (URL) recently changed to
https://kygenweb.net/breathitt/
Please update your bookmarks.

I would like to give this to someone who would be willing to take this information and run with it. Add to it, make corrections, etc. The Family Tree data file along with support files is 320m+, the picture folder contains 39,000+ pictures/documents (31.4GB). The database is in Legacy Family Tree (free, Windows) software. To get this database all I ask is you send a 1TB external hard drive to me, pay shipping both ways. Speaking of help, please take a quick look at the Research Requests page and see if you can help someone, or consider having your own request there.

If you're interested in contributing information to this site for other researchers, please contact me.

Try using the search form for this web site which is under the menu on the left side of this page. There is a lot of information here and that search form is a great tool for digging through it all.

A Few Words About The Content On This Site
1. I try to verify other web sites listed here are not scams. If you find one that I missed please let me know.
2. This site is a source of information for Breathitt County researchers. Information presented here and links to other web sites have been submitted by many different researchers. It is posted here in the interests of openly sharing information without censorship. If you have an issue regarding validity of information, especially on another web site, please take that up with the owner of the other web site. I am not a researcher of all families and certainly am in no position to be the arbitrator of family disputes and unless another web site is clearly a scam I will not remove a link because someone doesn't like it. Thanks for your consideration.
3. This web site is continually being updated. PLEASE bookmark ONLY the home page as some links do change. If you find any broken links please take a quick moment and contact me about it
Thanks ~ Scott
