Welcome to the Kentucky Footsteps Archives

When KY-FOOTSTEPS launched in February 1997, email lists were the main way genealogists shared discoveries. The list provided a place for posting obituaries and research notes without crowding the old query lists, and it quickly became a major contribution stream for the KYGenWeb Project.

Activity tapered off around 2014 as mailing lists faded, but the submissions from those years remain invaluable. This site preserves that collection so researchers can continue to access the materials shared by volunteers across Kentucky.

Using This Archive

KY Footsteps has two archives: Topic and County. Each archive preserves thousands of transcribed text files, many drawn from local Kentucky newspapers. The Date Index is for the Topic Archive.

Topic Archive

The Topics Archive groups file by type (Births, Deaths, Marriages, Cemeteries, Military, Surnames, and more). This is the best place to start if you know the kind of record you are looking for or want to explore a subject.
